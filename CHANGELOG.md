### Features

* automate versioned macOS releases  Let users download a verified app instead of building from source. Review versions and changelogs through release PRs before publishing.  - workflows: add release-please, draft releases, pinned actions, and   Conventional Commit PR title checks - build: stamp the app version and source commit into the bundle - scripts: package an arm64 ZIP with a SHA-256 checksum; verify uploads   and preserve existing assets when retrying - tests: add 10 tests for package integrity and release publishing - README/docs: explain downloads, release setup, and signing limits - gitignore: exclude generated release packages  GitHub Actions must be allowed to create PRs.
